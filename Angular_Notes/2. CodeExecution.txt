@Component contains some decelarations used by angular
1. HTML template that controls  what renders in the DOM
2. CSS selector => defines how the component is used in HTML
3. Typescript class with behaviours for elements like inputs and actions or api req


3 files working together html, css, ts 

this @Component is a decorator in angular
@Component({
  selector: 'app-root',
  imports: [RouterOutlet],
  templateUrl: './app.html',
  styleUrl: './app.css'
})


- selector => helps to create a custom HTML element that can be used anywhere in the code like here app-root is used in 
            index.html main file as " <app-root></app-root> "

- imports => tells Angular what external features (components, directives, or pipes) your component’s template will use.

- templateUrl => used to import the html file that we have create for the page

- styleUrl => the stylesheet that we have created for the html file 

RouterOutlet is a directive/component provided by Angular Router that acts as a placeholder in your template.
           It tells Angular where to display the component for the current route (the page you’re visiting).
           Think of it as a “screen area” where your pages appear when you navigate.

    ********** RouterOutlet itself doesn’t define routes, but it’s the place where routes are displayed.********


With Angular module based components the application executes in this way

1. first the main.ts is loaded where it points to the app.module file with bootstrapModule
2. the bootstrapModule contins all the different components imports and Imports of other 
   Angular modules (BrowserModule, FormsModule, etc.)
3. then the index.html is executed where the <app-root/> is called to render the app component
4. which in html might contain other components like header, sidebar and footer inside with there selectors

In short flow will be =>
main.ts
   ↓
AppModule
   ↓
index.html
   ↓
<app-root> → AppComponent
   ↓
<app-header>, <app-sidebar>, <app-footer> (and other child components)
