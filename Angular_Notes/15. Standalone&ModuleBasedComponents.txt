-Standalone components dont require ngModule and dont depend on ngModule for operations 
 they manage there own dependencies, styles, and functionalities
-Standalone components can directly import other nessary features inside the @Component
 decorator and dont require ngModule to do so
 

 Modules based components

- 

| Concept                                            | Module-based   | Standalone       |
| -------------------------------------------------- | -------------- | ---------------- |
| Needs `app.module.ts`                              | ✅ Yes          | ❌ No             |
| Declare components in module                       | ✅ Yes          | ❌ No             |
| Import components directly inside other components | ❌ No           | ✅ Yes            |
| Recommended in latest Angular                      | ⚠️ Older style | ✅ Yes, preferred |
