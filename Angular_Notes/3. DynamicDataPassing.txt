for rendering dynamic data into html document

we can pass that data via the export component class that we create in component.ts file 
create a direct variable dont need to add let , var or const 
and pass in the values to that variable and  that can be  directly used in the html and 
passed via the string/object selector

{{ variableName.id or variableName.name}} etc
for image element it is different 

not like   <img src="{{selectedUser.avatar}}" alt="">   // using String Interpolation

but instead use it in this way know as 

           <img [src]="'assets/users/'+selectedUser.avatar" [alt]="selectedUser.name" />   //using Property Binding


Dynamic data passing is also known as data binding and it has types
1. One Way Data-Binding (data flows in a single direction i.e [Component to DOM])
    a. Interpolation
     => Passing data from component to HTML {{ title }},Works with text content only (not attributes).

    b. Property Binding
     => Achieved with square brackets [] added inside attributes <img [src] = "imageUrl" />
     
    c. Event Binding [DOM → Component]
     => Uses parentheses ( ). Done for events with $ sign event {$event}
     <button (click)="handleClick($event)">Click me</button>

2. Two Way Data-Binding (data flows in 2 direction i.e [Component -> View -> Component] with ngModel directive)
